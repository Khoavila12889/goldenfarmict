# Migration Guide: SQLite → PostgreSQL

## Overview

The project currently uses **SQLite** (`backend/data/company.db`) for development and single-server deployment. This guide provides a step-by-step path to migrate to **PostgreSQL** for production-scale deployment.

---

## Why PostgreSQL?

| Feature | SQLite | PostgreSQL |
|---------|--------|------------|
| Concurrent users | Limited (WAL mode helps) | Unlimited |
| Write performance | Single-writer | Multi-writer |
| Data integrity | Basic | Full ACID, constraints |
| Extensions | Limited | PostGIS, pgcrypto, etc. |
| Replication | None | Streaming replication |
| Management | File-based | Client-server |

## Step 1 — Install PostgreSQL

```bash
# Ubuntu / Debian
sudo apt install postgresql postgresql-contrib

# CentOS / RHEL
sudo yum install postgresql-server postgresql-contrib

# macOS
brew install postgresql@16
```

Create database and user:

```bash
sudo -u postgres psql

CREATE USER goldenfarm WITH PASSWORD 'your_strong_password';
CREATE DATABASE goldenfarmict OWNER goldenfarm;
GRANT ALL PRIVILEGES ON DATABASE goldenfarmict TO goldenfarm;
\q
```

## Step 3 — Convert schema (main changes)

### Replace SQLite-specific types

| SQLite | PostgreSQL |
|--------|------------|
| `INTEGER PRIMARY KEY AUTOINCREMENT` | `SERIAL PRIMARY KEY` or `INT GENERATED BY DEFAULT AS IDENTITY` |
| `REAL` | `NUMERIC` or `DOUBLE PRECISION` |
| `TEXT` | `TEXT` (no change) |
| `BLOB` | `BYTEA` |
| `datetime('now','localtime')` | `NOW()` or `CURRENT_TIMESTAMP` |

### Replace SQLite-specific functions in queries

| SQLite | PostgreSQL |
|--------|------------|
| `last_insert_rowid()` | `RETURNING id` |
| `group_concat(...)` | `string_agg(...)` |
| `INSERT OR IGNORE` | `INSERT ... ON CONFLICT DO NOTHING` |
| `LIKE` (case-sensitive) | `ILIKE` (case-insensitive) |
| `LOWER(col) LIKE '%text%'` | `col ILIKE '%text%'` |
| `datetime('now','localtime')` | `CURRENT_TIMESTAMP` |
| `date('now','localtime')` | `CURRENT_DATE` |

## Step 4 — Use the ORM layer (recommended)

The project already has SQLAlchemy models in `backend/app/models.py` and a session layer in `backend/app/core/session.py`.

### Switch from `get_conn()` to `core/db.py`

**Before (raw SQLite):**
```python
from ..core.database import get_conn

def list_items():
    conn = get_conn()
    rows = conn.execute("SELECT * FROM items WHERE status = ?", ('active',)).fetchall()
    conn.close()
    return [dict(r) for r in rows]
```

**After (using `core/db.py` — already supports PG):**
```python
from ..core.db import fetchall

def list_items():
    return fetchall("SELECT * FROM items WHERE status = :status", {'status': 'active'})
```

**Best — using ORM models:**
```python
from fastapi import Depends
from ..core.session import get_session
from ..models import Item
from sqlalchemy import select

def list_items(session=Depends(get_session)):
    result = session.execute(select(Item).where(Item.status == 'active'))
    return [dict(r._mapping) for r in result]
```

## Step 7 — Remove SQLite-specific code

### Files to update (one-by-one):

| File | Change |
|------|--------|
| `backend/app/core/database.py` | Remove `get_conn()`, `init_db()` — replace with ORM session |
| `backend/app/core/db.py` | Already compatible, but replace `last_insert_rowid()` with `RETURNING` |
| `backend/main.py` | Remove `seed_users()` SQLite dependency, use ORM seed |
| All routers | Replace `get_conn()` with `Depends(get_session)` + `core/db.py` |

### SQLite-specific PRAGMAs to remove:

```python
# Remove these (no equivalent in PG)
conn.execute("PRAGMA foreign_keys = ON")
conn.execute("PRAGMA journal_mode=WAL")
conn.execute("PRAGMA busy_timeout=10000")
```

PostgreSQL enforces foreign keys by default and handles concurrency natively.

## Migration Script Template

Create `backend/scripts/migrate_to_pg.py`:

```python
"""
One-time migration: SQLite → PostgreSQL
Usage: python backend/scripts/migrate_to_pg.py
"""
import sqlite3
import psycopg2
from psycopg2.extras import RealDictCursor

SQLITE_PATH = "backend/data/company.db"
PG_DSN = "host=localhost dbname=goldenfarmict user=goldenfarm password=your_password"

# 1. Read all data from SQLite
sq = sqlite3.connect(SQLITE_PATH)
sq.row_factory = sqlite3.Row

tables = [
    "users", "employees", "departments", "salary_slips",
    "todos", "bookings", "equipment", "business_trips",
    "licenses", "documents", "permissions", "notifications",
    "approval_settings", "approval_logs"
]

pg = psycopg2.connect(PG_DSN)
pg.autocommit = False
cur = pg.cursor()

for table in tables:
    rows = sq.execute(f"SELECT * FROM {table}").fetchall()
    if not rows:
        continue
    columns = list(rows[0].keys())
    placeholders = ", ".join([f"%({c})s" for c in columns])
    cols = ", ".join(columns)
    for row in rows:
        try:
            cur.execute(
                f"INSERT INTO {table} ({cols}) VALUES ({placeholders})",
                dict(row)
            )
        except Exception as e:
            print(f"Error inserting {table}: {e}")
            pg.rollback()
            raise
    print(f"Migrated {len(rows)} rows from {table}")

pg.commit()
cur.close()
pg.close()
sq.close()
print("Migration complete!")
```

## Rollback Plan

If migration fails:

```bash
# Restore SQLite backup
sqlite3 backend/data/company.db ".restore 'backend/backups/pre_migration.db'"

# Revert .env
# Comment out DATABASE_URL back to SQLite path

# Revert code changes
git checkout -- backend/
```

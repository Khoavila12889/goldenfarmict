# 📘 HƯỚNG DẪN SỬ DỤNG PHÂN HỆ LICENSE & PHẦN MỀM

*(Dành cho người dùng cuối – End-user)*

---

## I. TỔNG QUAN

Phân hệ License & Phần mềm quản lý bản quyền phần mềm (License Keys) và danh mục phần mềm đã cài đặt trong công ty. Hệ thống tự động cảnh báo License sắp hết hạn hoặc đã quá hạn.

---

## II. CÁC TAB

### 1. Tab License Keys
Danh sách các License Key phần mềm:
- **Product**: Tên phần mềm.
- **License Key**: Mã bản quyền.
- **Kích hoạt / Hết hạn**: Ngày bắt đầu và kết thúc hiệu lực.
- **Ghi chú**: Thông tin thêm (người dùng, vendor, ...).
- **Cảnh báo**: License sắp hết hạn (≤30 ngày) hiển thị màu vàng 🟡; quá hạn hiển thị màu đỏ 🔴.

### 2. Tab Software / Phần mềm đã cài
- Danh mục phần mềm theo loại (OS, Office, Design, Dev, Anti-Virus, Other).
- Mỗi mục hiển thị: tên, ngày đăng ký, ngày hết hạn, ghi chú.

---

## III. HƯỚNG DẪN THAO TÁC

### 1. Thêm License mới
1. Tab **License Keys** → nhấn **Thêm License**.
2. Nhập: Tên product, License Key, ngày kích hoạt/hết hạn (DD/MM/YYYY).
3. Nhấn **Lưu**.

### 2. Import hàng loạt
- Nhấn **📥 Import Excel** → chọn file Excel → hệ thống tự động nhập danh sách License.

### 3. Quét License
- Nhấn **🔍 Quét License** để kiểm tra và cập nhật trạng thái hết hạn.

### 4. Quản lý Software Items
- Tab **Phần mềm đã cài** → thêm danh mục phần mềm và từng item phần mềm.

---

## IV. QUYỀN HẠN

| Vai trò | Quyền |
|---------|-------|

Nguyên nhân gốc rễ: Docker Compose trên Windows đôi khi không reload .env file đúng cách khi container đã từng chạy trước đó (cached environment). Giải pháp: set env var explicit trong cmd session trước khi docker compose up.

Giờ test lại OnlyOffice — docUrl sẽ bắt đầu bằng http://127.0.0.1:8000 thay vì https://noibo.canhdongvang.vn.

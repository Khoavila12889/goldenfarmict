Thư mục này chưa có bản web PdfCraft

Chọn 1 trong 2 cách rồi đặt toàn bộ file vào đúng thư mục này (craft-web/pdfcraft/):

  1. Build từ source: cd pdfcraft/apps/pdfcraft-web && trunk build --release (cần Rust 1.95+), copy nội dung dist/ vào đây.
  2. Dùng release: tải pdfcraft-web-<ver>.zip từ GitHub Releases, giải nén vào đây.

Xong chạy: docker compose --profile craft up -d pdfcraft-web, mở webapp GoldenFarmICT → /craft-demo tab PDF.

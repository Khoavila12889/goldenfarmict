Thư mục này chưa có bản web GridCraft

Chọn 1 trong 2 cách rồi đặt toàn bộ file vào đúng thư mục này (craft-web/gridcraft/):

  1. Build từ source: cd gridcraft/apps/gridcraft-web && trunk build --release, copy nội dung dist/ vào đây.
  2. Dùng release: tải gridcraft-web-<ver>.zip từ GitHub Releases, giải nén vào đây.

Xong chạy: docker compose --profile craft up -d gridcraft-web, mở webapp GoldenFarmICT → /craft-demo tab Excel.

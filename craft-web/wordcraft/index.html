Thư mục này chưa có bản web WordCraft

Chọn 1 trong 2 cách rồi đặt toàn bộ file vào đúng thư mục này (craft-web/wordcraft/ ngang hàng docker-compose.yml):

  1. Build từ source: cd wordcraft/apps/wordcraft-web && trunk build --release, copy nội dung dist/ vào đây.
  2. Dùng release: tải wordcraft-web-<ver>.zip từ GitHub Releases, giải nén vào đây.

Xong chạy: docker compose --profile craft up -d wordcraft-web, mở webapp GoldenFarmICT → /craft-demo tab Word.
